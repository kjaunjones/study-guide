DAY 1 · 24 Nov · 3 HOURS · M(xii)

Python variables

Learn — 40 minutes

Strings, integers, floats, Booleans and f-strings

Check your environment in the VS Code terminal:

python3 --version
git --version
mkdir garage-management-system
cd garage-management-system
git init

Create main.py, README.md and .gitignore. A variable binds a name to a value. Quoted digits such as "3008" are strings; 35000 is an integer; 75.5 is a float; False is a Boolean. Use print() to display values. An f-string inserts expressions in braces.

rate = 65.5
print(f"Rate: £{rate:.2f}")

Practice: predict the result of assigning a variable twice; explain why registration is text; format a fee of 100.0 to two decimal places.

vehicle_make = "Peugeot"
# Add your other variables
print("=== GARAGE JOB CARD ===")

Target output:

Vehicle: Peugeot 3008
Registration: AB12 CDE
Year: 2024
Mileage: 35000 miles
Diagnostic Fee: £75.50
Job Completed: False
